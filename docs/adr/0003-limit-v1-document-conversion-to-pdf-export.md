# Limit v1 document conversion to PDF export

V1 includes DOCX → PDF and Markdown → PDF alongside image conversion. PDF → DOCX, OCR, and other text formats are deferred to keep the first release useful and its acceptance criteria bounded; video and other converter families remain future work.

Image scope is recorded separately in ADR 0004. Document fidelity policies and converter dependencies must be established through documented investigation and fixtures before routes are advertised.
